# Shared mutation workflows

The tagged references/fixtures-ooxml submodule owns eight workflow scenarios,
19 expanded cases, four byte-pinned inputs and stable case identities.
features/shared.json enables Bun execution through an in-memory lifecycle overlay.
Then bindings call native patchOffice and assert saved outcomes and part custody.

The code-free distribution has a new manifest seal. Its fixture hashes, Gherkin
and expanded case identities are retained. Historical whole-pack seals are only
provenance, not this distribution identity. Runtime/test source recipes are absent.

Planned/unmapped contracts earn no credit. The native outcome interchange schema
remains version 2; a complete cross-language exporter is separate work.
